# AI Marine Risk Radar

Учебный прототип оценки рисков рейса танкера: форма параметров, проверка IMO, сценарные индикаторы, карта и передача оценки риск-офицеру через n8n.

## Запуск интерфейса

Требуется Python 3. В папке проекта выполните:

```sh
python -m http.server 8765 --bind 127.0.0.1
```

Откройте http://127.0.0.1:8765. Интерфейс использует внешние CDN для оформления, карты и графиков, поэтому требуется интернет.

Альтернативная оболочка `app.py` требует Streamlit (`python -m pip install streamlit`), запуск: `python -m streamlit run app.py`. Основной рекомендуемый запуск — HTTP-сервер выше.

## Сервер расчёта

**При проверке 26 ноября 2026 прежний адрес `https://lavrik.app.n8n.cloud` вернул `404 — No instance here`. Интерфейс открывается, но полный расчёт сейчас требует восстановления или подключения рабочего n8n.**

1. Импортируйте `AI_Marine_Risk_Radar_FULL.json` в свой n8n.
2. Настройте подключения OpenAI и Basic Auth формы офицера в n8n. Секреты храните в credentials n8n.
3. Замените старый домен n8n в `index.html` и `terminal-v3.js` на домен своей установки, включая проверку адреса формы офицера.
4. Опубликуйте workflow и проверьте отправку оценки, сохранение журнала и решение офицера.

Подробности: [ПОДКЛЮЧЕНИЕ_ИТОГ.md](ПОДКЛЮЧЕНИЕ_ИТОГ.md). Файл `AI_Marine_Risk_Radar_Workflow_v3.json` сохранён для проверок совместимости; для подключения используйте FULL.

## Локальные проверки

Требуется Node.js; сторонние пакеты не нужны:

```sh
node test-v3.cjs
node test-full.cjs
```

Эти проверки проверяют правила и структуру workflow, но не подтверждают работу облачного сервера, API или учётных записей.

## Ограничения

AIS, санкционные реестры, актуальные котировки и страховые тарифы не подключены. Погода запрашивается для одной контрольной точки. Маршрут на карте — схема из ограниченного каталога, не навигационная прокладка. Итоговый балл — максимум известных сценарных индикаторов, не вероятность происшествия. Решение принимает человек; автоматического одобрения рейса нет.
